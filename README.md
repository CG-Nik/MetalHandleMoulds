# MetalHandleMoulds
This mod adds moulds for the seven metal handles in A Township Tale.  
This mod needs to be on both the Client and the Server to work properly.  
This mod requires that you also have https://github.com/CG-Nik/CustomRecipesAPI downloaded to work properly.  
I highly recommend using https://github.com/Circl-NoE/EnoughIron, as it fixes the issue where the created handles will be visually made of Iron.  

Six of the seven moulds can be found as loot in chests, or can be made as temporary moulds with the Standard Mould Press.  
The mould for the Knuckle Handle can't be found as loot, and instead can only be made as a temporary Hebios mould.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
